# Hunch initial scope

Build a reusable npm CLI and self-hosted GitHub App for Jev semantic PR review. TypeScript projects use a typed hunch.config.ts; Rust and other projects can use hunch.toml. Configs support plain-English rules and standard installed Agent Skills, GitHub owner/repo references and GitHub URLs. Include scoped AGENTS.md guidance.

Research real TypeSafe/Vercel API access and AI ecosystem conventions. Use mattpocock/skills, install relevant skills in this project, and configure Hunch to review its own architectural conventions. Rules must require semantic judgment, not duplicate linting or type checking. Reports should be readable locally without needing a PR.

The prototype is a reference, with no architecture frozen. Adversarially assess security, semantic coverage, deployment reliability, packaging and false claims. Configure the GitHub repository where available. Use existing credentials if available, otherwise finish setup files. Do not claim a deployment, model quality benchmark or npm publication that was not actually completed.
